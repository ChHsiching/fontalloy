# Normalization defaults to the grid school; optical ratio is the knob

Donor CJK glyphs scale by k = min(2A/U, 0.95·(typoAsc + |typoDesc|)/H_ink): the terminal grid wins by default (CJK advance = exactly 2× the Latin advance — the Maple Mono CN approach), with an overflow guard as the ceiling. The optical school (Han ink ≈ 1.23× cap height, the Noto native pairing) is an adjustable knob in the recipe and the interface. Vertical displacement is zero: scripts share one baseline, the CJK ideographic em box sits at [−0.12em, +0.88em] by convention, and no top alignment happens. Line height fully inherits the base font (hhea/typo untouched); only usWinAscent/Descent grow, and only to prevent clipping. Donor advances follow UAX #11: Fullwidth/Wide take two cells, Halfwidth/Narrow and Ambiguous take one — an ambiguous codepoint the base font already covers stays with the base font, a corollary of absence-never-overrides. Width policy for fullwidth quotes and dashes is a recipe option. Rationale: in a terminal the 2:1 grid is correctness, not taste; measured with JetBrains Mono × Source Han/Noto under the default k, the Han ink span lands entirely inside the base font's existing metrics — zero table changes.
